# notes/

[`proof.md`](proof.md) is the proof written out for a human reader, meant to be read in about an hour. It covers:
- the statement and the trust base;
- the route in one paragraph;
- each step of the argument in full, with the Lean declaration that carries it and a link to its file and line in
  [`../formalization/`](../formalization/README.md);
- how the result was checked;
- what is not claimed.

The paper in [`../paper/`](../paper/README.md) covers the same ground in a more formal style. Where either text says what a Lean
lemma states, the lemma is the authority.
